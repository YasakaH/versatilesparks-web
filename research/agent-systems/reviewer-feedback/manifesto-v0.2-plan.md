## Architecture Locks

The following are locked unless ≥3 reviewers independently identify them as structural flaws:

1. **Eight-node execution loop** (Perception → Decision → Planning → Scheduling → Execution → Verification → Recovery → Learning)
2. **Six architectural layers** (Memory, Economics, Observability, Security, Governance, Runtime)
3. **Surface abstraction** (same architecture across Browser, Desktop, Terminal, API, Mobile, IoT)
4. **Proposed (not proven)** framing — this is a proposal, not a definitive statement

Any proposed change to these requires at least three independent reviewer consensus to proceed to v2.x.
