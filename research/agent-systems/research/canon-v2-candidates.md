## Evaluation Criteria

A candidate moves from this file into a proposed Canon v2 change ONLY when:

1. The same structural issue appears in **≥3 independent packages** (not just sequential ones)
2. The issue causes **repeated friction** (authors spending >30 minutes resolving it manually)
3. The fix **cannot be addressed** through editorial clarification in the specification

If a candidate meets all three criteria, it becomes a formal change proposal. The proposal includes:
- Description of the issue
- Examples from affected packages
- Proposed Canon/Taxonomy change
- Migration plan for existing packages

---

## Canon v1.x Change Policy

**Canon v1.x is frozen for structural changes.**

Allowed:
- Typographical corrections
- Clarifications that don't change meaning
- Cross-reference updates

Forbidden:
- Adding new nodes
- Removing nodes
- Changing node definitions
- Restructuring tiers
- Modifying dependencies
