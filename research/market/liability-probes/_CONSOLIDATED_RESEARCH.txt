# 3. THE CLAIMS INVESTIGATION GAP

## Current State (Manual, Fragmented)

When an AI agent causes loss:
  1. Company exports logs from 3-5 different systems (IDE, cloud, git, comms)
  2. Security engineer manually reconstructs timeline (30+ hours minimum)
  3. Claims adjuster tries to map: tool called? permissions? authorization?
  4. No standardized evidence format exists
  5. Weeks later: coverage decision or denial

## Concrete Cost Data
  - PocketOS incident: $57K loss, 9 seconds execution, 30+ hours investigation
  - Cyber IR retainers: $10K-$100K/year, mid-market engagement $25K-$500K
  - AI forensics market: $4.8B (2025) → $28.6B (2035), 19.5% CAGR
  - AI claims automation reduces cost per claim 30-40% (industry data)

## What Insurers Actually Need (per article analysis)
  "Are inputs, outputs, tool calls, human overrides, system prompts 
  captured?" — LinkedIn article on AI agent insurance
  "After a loss, the insurer needs evidence: Which tool did the agent call?
  What permissions did it have? Who approved the action? What changed?
  Can the record be trusted after the fact?" — 2muchcoffee.com

# 4. INFRASTRUCTURE GAP

## What Exists
  - ProofSnap: Blockchain timestamps for AI outputs (chatbot liability)
  - TrueScreen: QTSP digital seals + eIDAS timestamps (general data cert)
  - SWEAR: Digital evidence authentication (physical security footage)

None capture FULL AGENT EXECUTION provenance (tool calls, decisions,
state changes, sequence, evidence artifacts).

## The Missing Primitive (Björn Roberg, Apr 2026)
  "Record → Replay → Expire"
  Record: inputs, outputs, side-effect evidence, timestamps
  Replay: conformance test against live target
  Expire: TTL-bound attestation that re-verifies on drift

No shipping product has the TTL/expiry piece.

## Our EPR Format Maps To This
  Event model → Record
  Diff engine → Replay
  TTL not yet built → Expire

# 5. FRAMEWORK COMPATIBILITY

Current agent frameworks produce proprietary, non-standardized traces:
  - OpenAI Agents SDK: proprietary format
  - LangGraph: LangSmith traces (debugging, not underwriting)
  - CrewAI: log format
  - MCP servers: protocol-level logging

No framework emits a standardized insurance-grade evidence packet.
Every carrier (Mount, Klaimee, Armilla) builds their own data pipeline
from scratch.

  "Existing carriers either exclude AI risk, price it badly, or avoid
  it entirely because they do not know how to assess deployed AI
  systems." — Mount job posting

# 6. COMPETITIVE THREATS TO THE THESIS

  - If LangSmith/Langfuse expands into compliance exports → Layer 3 shrinks
  - If OpenAI/Anthropic standardizes execution traces → proprietary lock-in
  - If carriers build internal tooling → fragmented, no standard
  - If regulators define the format → commodity

  The strongest defense: the TTL/expiry primitive. Carriers won't build
  this. Framework vendors won't prioritize it. Regulators haven't
  specified it. It's the one piece that requires independent infrastructure.

# 7. KEY UNANSWERED QUESTION

  "How many AI claims have actually been paid?"

  We have incidents (PocketOS, Replit, Air Canada, Chevrolet) but no
  evidence that any AI liability insurance policy has paid a claim yet.
  The market is pre-claims. That means:
    - Carriers are pricing risk without loss data
    - The first major claim will validate or invalidate the category
    - Infrastructure built now is forward-looking
