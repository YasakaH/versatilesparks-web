# Python Browser Automation Cookbook

## Working Smarter with nodriver

Version 1.0.0

Welcome to the *Python Browser Automation Cookbook*. This book provides practical, production-ready recipes for browser automation using Python and nodriver.

**Who this is for:** Developers who want to automate browser tasks reliably — from web scraping and form filling to monitoring and data extraction.

**How to use this book:** Each chapter is organized around a specific capability. Start with Chapter 0 for setup, then work through the chapters in order. Each recipe is self-contained but builds on previous chapters.

**About nodriver:** nodriver is a modern Python library for browser automation using Chrome DevTools Protocol (CDP). It is lightweight, async-native, and does not require WebDriver or Selenium.
