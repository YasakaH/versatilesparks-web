# Materials Reference

## Glass

| Property | Value |
|----------|-------|
| Base color | `#FFFFFF` |
| Opacity | 5-10% |
| Backdrop blur | 20px Gaussian |
| Border | 0.5px, `#FFFFFF` at 30% opacity |
| Corner radius | 2px |
| Shadow | None (transparent by nature) |

**Used for:** Containers, panels framing architecture views, overlays showing transparent layers.

---

## Brushed Aluminum

| Property | Value |
|----------|-------|
| Base color | `#2A2F3E` |
| Grain | Vertical, subtle (2% luminance variation) |
| Reflectivity | 20% (subtle environment reflection) |
| Border | 1px, `#3A3F4E` (slightly lighter) |
| Corner radius | 1px (sharp, machined) |

**Used for:** Hardware representations, server chassis, physical machinery, node enclosures in architecture diagrams.

---

## Carbon Fiber

| Property | Value |
|----------|-------|
| Base color | `#1A1D2A` |
| Weave | 45° diagonal, 4px grid spacing |
| Weave opacity | 15% (subtle texture) |
| Border | 0.5px, `#2A2D3A` |
| Corner radius | 0px (raw, functional) |

**Used for:** High-performance components, browser internals, rendering engines, GPU representations.

---

## Matte Polymer

| Property | Value |
|----------|-------|
| Base color | `#1E2230` |
| Texture | None (smooth matte) |
| Shadow | Soft, 4px offset, 30% opacity |
| Corner radius | 2px |
| Border | 0.5px, `#2E3240` (optional) |

**Used for:** General UI elements, cards, buttons, node representations in architectural diagrams.

---

## Soft Acrylic

| Property | Value |
|----------|-------|
| Base color | `#141820` |
| Opacity | 10% |
| Backdrop blur | 10px Gaussian |
| Corner radius | 0px (full-width panels) |

**Used for:** Background panels, section dividers, atmospheric depth layers.

---

## Neon Edge

| Property | Value |
|----------|-------|
| Color | Electric Cyan (`#00D4FF`) or Azure Blue (`#0080FF`) |
| Width | 1-2px |
| Glow | 4px, 50% opacity of the same color |
| Opacity | 100% for active paths, 40% for inactive |

**Used for:** Data flow lines, connection paths between nodes, active process indicators, energy flow visualization.
