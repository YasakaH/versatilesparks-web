# Changelog

All notable changes to the Browser Automation Playbook and Production Reference Library.

## 2.0.0 — 2026

### Browser Automation Playbook

Initial Production Engineering Edition release.

- **New:** Automation Engineering Mindset chapter with maturity ladder, cost curve, and 12 engineering principles
- **New:** Chapters 1-14 restructured for production engineering (not just recipes)
- **New:** Enhanced introductions with "Cost of Getting This Wrong" and incident-format stories
- **New:** Engineering Review boxes at the end of every chapter
- **New:** Production Operations Guide with operator checklists and incident timeline
- **Improved:** All flowcharts upgraded to state machine diagrams and decision trees
- **Improved:** Cross-references throughout — every chapter links to related content
- **Improved:** Nodriver consistency pass across all code examples

### Production Reference Library

- **Architecture Field Guide:** 13 decision matrices, 4 reference architectures, architecture smells, cost table
- **Failure Playbook:** 15 failure patterns with severity, recovery verification, and recovery decision tree
- **Pattern Catalog:** 15 engineering patterns with Intent/Context/Forces and relationships appendix
- **Design Review Checklist:** 50+ checks across 8 categories, red flags, build size estimates
- **War Stories:** 20 production incidents with root cause analysis and prevention links
