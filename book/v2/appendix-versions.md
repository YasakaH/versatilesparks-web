## Compatible Versions

This book was verified against the following software versions:

| Component | Version |
|-----------|---------|
| Python | 3.11+ |
| nodriver | 0.50.x |
| Chrome/Chromium | 130+ |
| OS | Linux, macOS, Windows (Docker recommended) |

## Supported Platforms

- [✓] Linux (production)
- [✓] macOS (development)
- [✓] Windows (development via WSL2 recommended)

## Unsupported

- [✗] Internet Explorer
- [✗] Safari (limited CDP support)
- [✗] Headless Chrome on 32-bit systems
