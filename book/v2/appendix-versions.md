## Compatible Versions

This book was verified against the following software versions:

| Component | Version |
|-----------|---------|
| Python | 3.11+ |
| nodriver | 0.50.x |
| Chrome/Chromium | 130+ |
| OS | Linux, macOS, Windows (Docker recommended) |

## Supported Platforms

- [Y] Linux (production)
- [Y] macOS (development)
- [Y] Windows (development via WSL2 recommended)

## Unsupported

- [X] Internet Explorer
- [X] Safari (limited CDP support)
- [X] Headless Chrome on 32-bit systems
