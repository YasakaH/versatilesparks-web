## Get Started

### 1. Read the Book
Start with the Automation Mindset chapter. It explains the engineering philosophy that makes everything else make sense.

Then read sequentially through Chapters 1-14. Each chapter builds on the previous one.

### 2. Run the Starter Kit
After Chapter 8, open `code/starter-kit/` for a reusable automation project structure.

### 3. Reference the Library
Keep these open while designing or debugging:

- **Architecture Field Guide** — when choosing between approaches
- **Failure Playbook** — when something breaks
- **Pattern Catalog** — when designing new systems
- **War Stories** — to learn from real incidents
- **Design Review Checklist** — before deploying anything

## System Requirements

- Python 3.11+
- Chrome 130+ (or Chromium)
- nodriver 0.50.x
- Docker (recommended for production deployment)
