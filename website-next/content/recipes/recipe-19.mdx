Dumping and re-injecting active cookie structures allows you to recreate authenticated states without stepping through login triggers.

```python
import json
import nodriver as uc

async def save_cookies(page, filename="cookies.json"):
    cookies = await page.send(uc.api.network.get_cookies())
    with open(filename, "w") as f:
        json.dump(cookies, f)
```
