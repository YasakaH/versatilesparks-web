Intercept and modify requests at the network boundary using the low-level Chrome DevTools Protocol.

```python
import nodriver as uc

async def main():
    browser = await uc.start()
    page = await browser.get("https://example.com")
    
    # Enable network interception
    await page.send(uc.api.network.enable())
```
