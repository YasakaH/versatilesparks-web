When every page load triggers a CAPTCHA, your browser fingerprint is being detected as non-human.

### Root Cause

Detection services check: `navigator.webdriver`, CDP presence, TLS handshake signatures, and behavioral timing.

### The Fix

Apply stealth patches before the browser creates its first connection:

```python
from nodriver import start

browser = await start(
    headless=True,
    arguments=[
        "--disable-blink-features=AutomationControlled",
    ]
)
```

If CAPTCHAs persist, rotate the full fingerprint (viewport, user-agent, WebGL vendor).
