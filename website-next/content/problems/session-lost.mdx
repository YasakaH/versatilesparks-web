Session cookies are stored in memory by default. When the browser restarts, authenticated state disappears.

### Root Cause

nodriver starts in ephemeral mode by default. The profile directory is temporary unless explicitly set.

### The Fix

Persist the profile:

```python
from nodriver import start

async def auth_once():
    browser = await start(user_data_dir="./persistent-profile", headless=False)
    # log in manually, then reuse the same profile next time
```

On subsequent runs, the session cookies survive browser restarts as long as the same `user_data_dir` is used.
