Unexpected termination (SIGKILL, power loss) during SQLite write operations on Cookies, History, or Login Data databases.

### Recovery

Delete or restore the corrupted profile directory from backup. Browser recreates it on next launch.

### Recommendation

Always use graceful shutdown (SIGTERM) and monitor process exit codes.
