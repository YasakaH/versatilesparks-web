## Semantic Layer
WebDriver is a W3C standard protocol for browser automation. It uses HTTP REST endpoints and is the foundation for Selenium.

## Narrative Layer
WebDriver is older and less capable than CDP, but remains the only standard cross-browser protocol. Tools like Selenium use it; Playwright and Puppeteer use CDP instead.
