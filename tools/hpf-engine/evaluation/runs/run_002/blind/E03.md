# Nodriver - CDP without WebDriver

**Definition:** Nodriver is a library that connects to the browser directly via CDP over WebSocket, bypassing WebDriver entirely.

## Core Mechanics
- Nodriver is a library that connects to the browser directly via CDP over WebSocket, bypassing WebDriver entirely

## Examples
- By connecting directly to CDP, nodriver avoids the overhead and limitations of Selenium/WebDriver
- It is Python-native, async, and avoids the Selenium binary dependency
