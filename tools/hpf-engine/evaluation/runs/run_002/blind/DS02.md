--- Avoiding Bot Detection ---
Techniques to avoid browser fingerprinting detection: spoof WebDriver flag, override navigator properties, use realistic user agents, mimic human behavior. Scrapers get blocked because sites detect automated behavior patterns: fixed intervals, no mouse movement, headless browser signatures.

--- Blocking Detection and Rate Limiting ---
Sites detect scrapers through behavioral signals: request frequency, IP reputation, missing headers, no JavaScript execution, headless browser signatures, and abnormal mouse/keyboard patterns. Rate limiting blocks by counting requests per time window. Captchas add a proof-of-human step. Bans escalate from temporary (429 status) to permanent (403/blocked IP).

--- Isolated Browser Profiles ---
Browser profiles provide isolated environments with persistent storage, cookies, and local state.
