# Question: Selenium vs Playwright
Mode: compare

=== Answer A ===
--- Playwright Browser Automation Framework ---
Playwright is a browser automation framework by Microsoft that uses CDP directly over WebSocket. It supports Chromium, Firefox, and WebKit with a single API. Key features: auto-waiting for elements, network interception, browser contexts for isolation, trace viewer for debugging, and codegen for test recording.

--- Selenium Browser Automation Framework ---
Selenium is a browser automation framework using the W3C WebDriver protocol. It supports multiple browsers (Chrome, Firefox, Edge, Safari) through browser-specific drivers. Selenium has three components: WebDriver API, IDE for record-and-playback, and Grid for distributed execution.

--- W3C WebDriver Protocol ---
WebDriver is a W3C standard protocol for browser automation. It uses HTTP REST endpoints and is the foundation for Selenium.
