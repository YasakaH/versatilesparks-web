# TROUBLESHOOTING

| Issue | Fix |
|-------|-----|
| EPUB has formatting issues | Use Kindle Previewer to check. Fix in CSS and re-export. |
| Cover rejected | Ensure it's at least 1000x625px, 72 DPI. Our covers meet this. |
| "This title already exists" | KDP found a match. Check your Bookshelf for a draft. |
| Category not available | KDP's category list changes. Pick the closest match. |
| Royalty rate lower than 70% | Check delivery cost. For EPUB-only files, this should be minimal. |
